# FreqCounterOS 上位机通信协议

## 1. 协议概述

### 1.1 通信方式

本频率计系统支持两种通信方式：
- **TCP Socket**（推荐）
- **UART 串口**

两种通信方式使用**完全相同的命令协议**，上位机可以选择任意一种方式与设备进行通信。

### 1.2 通信参数

#### TCP连接参数
| 参数 | 值 |
|------|------|
| IP地址 | 192.168.1.115（默认） |
| 端口号 | 5025 |
| 协议 | TCP |
| 连接模式 | 服务端模式（设备作为Server） |

#### UART串口参数
| 参数 | 值 |
|------|------|
| 波特率 | 9600 bps |
| 数据位 | 8 bit |
| 停止位 | 1 bit |
| 校验位 | None |
| 流控制 | None |

### 1.3 数据帧格式

#### 命令帧格式
```
[命令字符串]\n
```
- 所有命令以ASCII字符串形式发送
- 命令必须以**换行符 `\n` (0x0A)** 结尾
- 命令不区分大小写（建议大写）
- 最大命令长度：1500字节

#### 响应帧格式
```
[响应数据]\n
```
- 所有响应以ASCII字符串形式返回
- 响应以**换行符 `\n` (0x0A)** 结尾
- 响应数据根据命令类型不同而变化

### 1.4 超时建议
- 命令响应超时：1000ms
- 频率测量超时：取决于闸门时间设置（建议设置为闸门时间 + 500ms）
- 连接超时：5000ms

### 2.2 频率测量命令

#### 2.2.1 读取频率 (`READ?`)

**命令格式：**
```
READ?\n
```

**功能说明：**

- 当 `FREF ≤ 750000 Hz` 时：使用低频模式（周期法）
- 当 `FREF > 750000 Hz` 时：使用高频模式（等精度法）

**响应格式：**
```

```

**响应数据说明：**

|------|------|------|------|------|
| 频率值 | double | %.5f | Hz | 10000000.12345 |

**示例：**
```
上位机发送: READ?\n
设备响应:   10000000.12345\n
```
（表示测量频率为 10.00000012345 MHz）

#### 2.3.3 设置闸门时间 (`FREQ:GATE:TIME`)

**命令格式：**
```
FREQ:GATE:TIME <时间值>\n
```

**功能说明：**  
设置频率测量的闸门时间。闸门时间越长，测量精度越高，但测量时间也越长。

**参数说明：**
| 参数 | 类型 | 单位 | 常用值 | 说明 |
|------|------|------|--------|------|
| 时间值 | double | 秒 | 0.001, 0.01, 0.1, 1, 10 | 闸门时间（秒） |

**支持的闸门时间：**
| 输入值（秒） | 实际值（ms） | 计数器最大值 | 适用场景 |
|-------------|-------------|-------------|----------|
| 0.001 | 1 ms | 312,499 | 快速测量，精度较低 |
| 0.01 | 10 ms | 3,124,999 | 中等速度测量 |
| 0.1 | 100 ms | 31,249,999 | 默认值，平衡精度和速度 |
| 1 | 1000 ms | 312,499,999 | 高精度测量 |
| 10 | 10000 ms | 3,124,999,999 | 超高精度测量 |

**响应格式：**
```
[闸门时间]\n
```

**响应数据说明：**
- 返回实际设置的闸门时间（单位：ms）

**示例1 - 设置1秒闸门时间：**
```
上位机发送: FREQ:GATE:TIME 1\n
设备响应:   1000.000\n
```

**示例2 - 设置100ms闸门时间：**
```
上位机发送: FREQ:GATE:TIME 0.1\n
设备响应:   100.000\n
```

**注意事项：**
- 输入单位为**秒**，返回单位为**毫秒**
- 非标准闸门时间可能无法精确设置

### 2.5 PPM和时间测量命令

#### 2.5.1 设置PPM阈值 (`PPM`)

**命令格式：**
```
PPM <值>\n
```

**功能说明：**  
设置PPM（Parts Per Million）阈值，用于启动时间测量的判断条件。

**参数说明：**
| 参数 | 类型 | 单位 | 说明 |
|------|------|------|------|
| 值 | int | ppm | PPM容差阈值 |

**响应格式：**
```
[PPM值]\n
```

**示例 - 设置100ppm阈值：**
```
上位机发送: PPM 100\n
设备响应:   100\n
```

**应用场景：**  
在启动时间测量中，当频率偏差在 ±PPM 范围内时，认为信号已稳定。

---

#### 2.5.2 初始化启动时间测量 (`INIT`)

**命令格式：**
```
INIT\n
```

**功能说明：**  
初始化并启动启动时间测量流程。该命令会：
1. 清零启动时间计数器
2. 开始连续测量频率
3. 当频率偏差在PPM阈值内时，记录启动时间

**测量逻辑：**
- 连续进行1000次频率测量
- 每次测量间隔为 `START_GATE_TIME + 0.02ms`
- 当满足 `|FRppm| ≤ PPM` 时，记录当前时间并结束测量
- 如果1000次测量后仍未满足条件，返回最后一次测量时间

**响应格式：**
```
0\n
```

**响应说明：**
- `0` - 启动时间测量已开始（阻塞执行）

**示例：**
```
上位机发送: INIT\n
设备响应:   0\n
```

**注意事项：**
- 该命令是**同步阻塞**执行
- 需要先设置好PPM和START_GATE_TIME参数
- 执行时间取决于信号稳定速度

---

## 4. 使用示例

### 4.1 TCP连接示例（Python）

```python
import socket

# 创建TCP连接
client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
client.connect(('192.168.1.115', 5025))

def send_command(cmd):
    """发送命令并接收响应"""
    client.sendall((cmd + '\n').encode())
    response = client.recv(1024).decode().strip()
    return response

# 查询设备信息
print("设备信息:", send_command('*IDN?'))

# 配置参考频率为10MHz
print("设置参考频率:", send_command('CONF:FREQ 10000000'))

# 设置闸门时间为1秒
print("设置闸门时间:", send_command('FREQ:GATE:TIME 1'))

# 测量频率
print("频率测量:", send_command('READ?'))

# 关闭连接
client.close()
```

### 4.2 TCP连接示例（C#）

```csharp
using System;
using System.Net.Sockets;
using System.Text;

class FreqCounterClient
{
    private TcpClient client;
    private NetworkStream stream;
    
    public FreqCounterClient(string ip, int port)
    {
        client = new TcpClient(ip, port);
        stream = client.GetStream();
    }
    
    public string SendCommand(string command)
    {
        // 发送命令
        byte[] data = Encoding.ASCII.GetBytes(command + "\n");
        stream.Write(data, 0, data.Length);
        
        // 接收响应
        byte[] buffer = new byte[1024];
        int bytesRead = stream.Read(buffer, 0, buffer.Length);
        return Encoding.ASCII.GetString(buffer, 0, bytesRead).Trim();
    }
    
    public void Close()
    {
        client.Close();
    }
}

// 使用示例
```


### 4.4 完整测量流程示例

```python
import socket
import time

class FreqCounter:
    def __init__(self, ip='192.168.1.115', port=5025):
        self.client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.client.connect((ip, port))
        self.client.settimeout(5.0)
    
    def send(self, cmd):
        """发送命令并返回响应"""
        self.client.sendall((cmd + '\n').encode())
        response = self.client.recv(1024).decode().strip()
        return response
    
    def get_id(self):
        """获取设备信息"""
        return self.send('*IDN?')
    
    def set_freq_ref(self, freq_hz):
        """设置参考频率"""
        return self.send(f'CONF:FREQ {freq_hz}')
    
    def set_gate_time(self, time_sec):
        """设置闸门时间（秒）"""
        return self.send(f'FREQ:GATE:TIME {time_sec}')
    
    def measure_freq(self):
        """测量频率"""
        response = self.send('READ?')
        return float(response)
    
    def get_status(self):
        """获取状态"""
        status0 = self.send('SIG:STATUS0?')
        status1 = self.send('SIG:STATUS1?')
        return {'status0': status0, 'status1': status1}
    
    def measure_startup_time(self, ppm=100):
        """测量启动时间"""
        # 设置PPM
        self.send(f'PPM {ppm}')
        
        # 初始化测量
        self.send('INIT')
        
        # 读取结果
        response = self.send('READ:TIME?')
        return float(response)
    
    def close(self):
        self.client.close()

# 使用示例
if __name__ == '__main__':
    counter = FreqCounter()
    
    # 查询设备信息
    print(f"设备: {counter.get_id()}")
    
    # 配置测量参数
    counter.set_freq_ref(10000000)  # 10MHz
    counter.set_gate_time(1)         # 1秒闸门

    status = counter.get_status()
    print(f"状态: {status}")

    print(f"启动时间: {startup_time:.3f} ms")
    
    counter.close()
```

## 5. 错误处理

### 5.1 常见错误

| 错误类型 | 原因 | 解决方法 |
|---------|------|---------|
| 无响应 | 连接未建立 | 检查IP地址和端口号 |
| 无响应 | 命令格式错误 | 确保命令以`\n`结尾 |
| 响应错误 | 参数超出范围 | 检查参数值是否合法 |
| 测量超时 | 闸门时间过长 | 调整超时时间设置 |
| 连接断开 | 设备重启 | 重新建立连接 |

### 5.2 命令验证

设备对命令进行严格的字符串匹配，如果命令格式不正确：
- 不会返回任何响应
- 不会返回错误信息
- 连接保持打开状态

**建议：**
- 上位机实现超时机制
- 对关键参数进行验证
- 添加重试机制

## 6. 注意事项

### 6.1 命令发送规则

1. **换行符**：所有命令必须以 `\n` (0x0A) 结尾
2. **大小写**：命令建议大写，实际代码中区分大小写
3. **空格**：参数前必须有空格（如 `CONF:FREQ 10000000`）
4. **缓冲区**：设备接收缓冲区为1500字节

### 6.2 测量相关

1. **FREF设置**：
   - 必须在首次测量前设置
   - 影响测量模式选择（低频/高频）
   - 阈值：750000 Hz

2. **闸门时间**：
   - 输入单位为秒，内部转换为毫秒
   - 仅支持特定值（1, 10, 100, 1000, 10000 ms）
   - 非标准值可能无法正确设置

3. **测量时间**：
   - 实际测量时间 ≈ 闸门时间 + 50~100ms
   - 建议超时设置 = 闸门时间 + 500ms

4. **启动时间测量**：
   - `INIT` 命令是同步阻塞执行
   - 需要先设置PPM和START_GATE_TIME
   - 最多进行1000次测量循环

### 6.3 网络相关

1. **TCP连接**：
   - 设备同时只服务1个客户端
   - 新连接会替换旧连接
   - 发送 "quit" 可主动断开连接

2. **多客户端**：
   - 设备可以接受多个连接请求
   - 但同一时间只处理一个连接
   - 建议使用连接池管理

### 6.4 串口相关

1. **波特率**：固定为9600
2. **中断接收**：以换行符(0x0A)为帧结束
3. **缓冲区**：200字节接收缓冲区
4. **与TCP共享**：串口和TCP使用相同的命令处理函数

## 附录B：常见问题解答

**Q1: 为什么发送命令后没有响应？**

A: 检查以下几点：
1. 命令是否以 `\n` 结尾
2. TCP连接是否成功建立
3. 命令拼写是否正确（区分大小写）

**Q2: 频率测量结果不准确？**

A: 可能原因：
1. FREF设置不正确
2. 闸门时间过短
3. 基准时钟不稳定
4. 被测信号质量差

**Q3: 如何选择合适的闸门时间？**

A: 建议：
- 快速测试：10ms~100ms
- 常规测量：100ms~1s
- 高精度测量：1s~10s

**Q4: 可以同时连接多个客户端吗？**

A: 可以建立多个连接，但设备同一时间只处理一个客户端的请求。

**Q5: 串口和TCP可以同时使用吗？**

A: 可以，但两者共享命令处理逻辑，建议不要同时发送命令。
